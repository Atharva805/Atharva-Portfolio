# Atharva R Kulkarni — Neon Resume Website

## Files
- index.html — landing page
- resume.html — resume
- biodata.html — bio-data
- projects.html — projects and technology stack
- style.css — shared responsive neon/Netflix/Spotify-inspired styling
- script.js — mobile menu, scroll reveal and card interactions

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Host on GitHub Pages
1. Create a new GitHub repository.
2. Upload all six files to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.

## Host on Netlify
Drag the project folder into Netlify's deploy area, or connect the GitHub repository.

## Before submission
Replace the placeholder email, phone, GitHub and LinkedIn values with your actual details.
